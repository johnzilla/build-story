# Bundled fonts

Unmodified IBM Plex Sans variable font and IBM Plex Mono Regular, distributed
under the SIL Open Font License 1.1 in OFL.txt. Copyright 2017 IBM Corp.

Sources (downloaded 2026-09-27):
- https://github.com/google/fonts/tree/main/ofl/ibmplexsans
- https://github.com/google/fonts/tree/main/ofl/ibmplexmono

Fonts are served locally by the Remotion bundle. No runtime font download is
required. Characters outside these fonts' coverage may use system fallbacks.
